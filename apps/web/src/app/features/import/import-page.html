Importar favoritos

Sube el archivo HTML que exporta el navegador. Chrome, Edge y Brave lo llaman favoritos; Firefox, marcadores. LinkShelf quita los parámetros de rastreo, une las URLs equivalentes y te deja asignar una categoría a cada carpeta.

  • Chrome o Brave: Favoritos → Administrar favoritos → menú → Exportar favoritos.
  • Edge: Favoritos → … → Exportar favoritos.
  • Firefox: Marcadores → Administrar marcadores → Importar y respaldar → Exportar marcadores a HTML.
